# WORK-TI 人格测试

一款轻松有趣的职场人格测试小游戏。通过 37 道职场情境题，测出你在「职场 16 型人格」中的归属，并隐藏 1 道彩蛋题，有机会解锁 4 种隐藏人格。

## 功能简介

- 37 道情境题，全程点击操作，约 3 分钟完成
- 16 种常规人格 + 4 种隐藏人格
- 支持导出 / 保存测试结果报告
- 纯前端实现，无需登录、不上传任何数据，可本地运行

## 使用方式

### 网页版

在线访问部署后的页面，按提示作答即可。

本地预览：用任意静态服务器打开本目录 `web_tm/`（例如在该目录下启动一个本地服务后访问 `index.html`）。
